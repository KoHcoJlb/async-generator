# async-generator-macros

Procedural macros for `async-generator`: `generator!` and `try_generator!`.

Use the macros through the `async-generator` crate, which provides the runtime
and re-exports them through its default `macros` feature:

```toml
[dependencies]
async-generator = "0.1"
```

Requires Rust 1.88 or later.
